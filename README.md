# EduPortal - Modern School Portal Landing Page

A comprehensive, single-page school portal experience built with Material Design principles. This landing page creates an emotional journey from confidence and orientation through discovery, engagement, and readiness to take action.

## 🛠️ Setup & Usage

### Installation
1. Clone or download the project files
2. Ensure all three files are in the same directory:
   - `index.html`
   - `styles.css`
   - `script.js`

### Running the Portal
Simply open `index.html` in a modern web browser. No build process or server required.

### Browser Compatibility
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)
- Mobile browsers (iOS Safari, Chrome Mobile)

## 📊 Performance Considerations

- **Smooth 60fps animations** using CSS transforms and opacity
- **Intersection Observer** for efficient scroll detection
- **Event delegation** for optimal event handling
- **CSS-based animations** over JavaScript where possible
- **Debounced scroll events** for performance
- **Lazy loading support** for images

## 🔧 Customization Guide

### Changing Colors
1. Open `styles.css`
2. Modify CSS variables in the `:root` section
3. Primary, accent, and neutral colors are all tokenized

### Updating Content
1. Edit `index.html` section by section
2. Maintain semantic structure
3. Keep Material Icons class names for icons

### Adding Sections
1. Follow existing section pattern
2. Add corresponding navigation link
3. Ensure smooth scroll functionality

### Modifying Animations
1. Adjust timing functions in CSS variables
2. Modify intersection observer options in `script.js`
3. Change animation duration/easing as needed
